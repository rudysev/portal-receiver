# portal-airplay

An AirPlay receiver for Meta Portal devices: audio, screen mirroring, and AirPlay video. A
standalone GPL-3.0 app, one-tap installable from the [Immortal](https://github.com/starbrightlab/immortal)
Store, which integrates it at arm's length over a published contract.

**Status: planning.** The design is being charted as a wayfinder map in this repo's issues
(label `wayfinder:map`). There is no code yet.
